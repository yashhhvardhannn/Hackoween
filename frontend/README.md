# Hackoween landing page

A full-screen product hero built with React, TypeScript, Vite, and Tailwind CSS.
The oversized Pixie wordmark sits behind an isolated foreground robot to create
a simple layered poster composition.

## Run locally

```bash
npm install
npm run dev
```

From the repository root, `npm run dev` launches the same app on port 3000 for
workspace preview discovery.

## Validate a production build

```bash
npm run build
```

The foreground robot is a local transparent PNG in `public/`, so deployment does
not depend on an external image host.
